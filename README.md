## Description
This project demonstrates controlling 6 LEDs using an Arduino Uno R3 and a breadboard.  
The LEDs blink one after another with a custom delay time.  

## Components Used
- Arduino Uno R3
- Breadboard
- 6 LEDs (different colors)
- 6 Resistors (220Ω–330Ω)
- Connecting wires

## How it Works
Each LED is connected to a digital pin on the Arduino through a resistor.  
The Arduino code turns each LED ON and OFF in sequence with a set delay.
